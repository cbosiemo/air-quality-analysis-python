# Reports

This folder contains the final written and presentation outputs from the air quality analysis project.

## Files

- `Air_Quality_Report.pdf` – Full analytical report covering the dataset, cleaning process, temporal trends, pollutant relationships, predictive modelling, limitations, and public-health and policy implications.
- `Air_Quality_Presentation.pdf` – Stakeholder-focused presentation summarising the analytical approach, key findings, predictive modelling results, implications, limitations, and next steps.

These outputs complement the Jupyter notebook by presenting the analysis in concise, stakeholder-friendly formats.
