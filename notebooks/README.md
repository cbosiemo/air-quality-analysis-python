# Jupyter Notebook

This folder contains the main reproducible analysis notebook for the project.

The notebook covers:

- Data loading and initial exploration
- Data cleaning and preprocessing
- Missing-value assessment and treatment
- Temporal analysis of pollutant concentrations
- Daily, monthly and diurnal patterns
- Weekday versus weekend comparisons
- Pollutant and meteorological relationships
- Correlation analysis
- Data visualisation
- Linear regression and Random Forest modelling
- Interpretation of environmental and public-health implications

The analysis uses the original `AirQualityUCI.csv` dataset located in `data/raw/`.

## Running the notebook

The notebook can be run locally with Jupyter Notebook or opened in Google Colab.

Run the notebook from top to bottom to reproduce the main analysis.
