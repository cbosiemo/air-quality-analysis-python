# Raw Data

This folder contains the original dataset used for the analysis.

## Dataset

`AirQualityUCI.csv` contains hourly air-quality and meteorological measurements used as the starting point for this project.

The raw data are preserved in their original form. All cleaning and preprocessing steps are performed programmatically in the project notebook and Python script.

## Source

Air Quality Dataset  
UCI Machine Learning Repository

The dataset includes measurements of carbon monoxide (CO), benzene, nitrogen oxides (NOx and NO2), temperature, relative humidity, and absolute humidity.

Missing measurements in the original dataset are represented by the sentinel value `-200`.
