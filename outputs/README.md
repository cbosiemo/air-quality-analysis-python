# Analysis Outputs

This folder contains key outputs generated by the air quality analysis.

## Files

- `correlation.csv` – Pairwise correlations among pollutant and meteorological variables.
- `model_results.csv` – Performance metrics from the predictive modelling workflow.
- `summary_stats.csv` – Summary statistics for the main pollutant and weather variables.

These outputs are generated from the processed AirQualityUCI data and support the findings presented in the notebook and report.
