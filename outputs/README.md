# Analysis Outputs

This folder contains reproducible tables and visual outputs generated by the air quality analysis.

## Files

- `correlation.csv` – Pairwise Pearson correlations among pollutant and meteorological variables.
- `missingness_before_cleaning.csv` – Percentage of missing observations by variable before NMHC exclusion and time-based interpolation.
- `model_results.csv` – Performance metrics for the Linear Regression and Random Forest benzene models.
- `summary_stats.csv` – Descriptive statistics for the main pollutant and meteorological variables.

## Figures

The [`figures/`](figures/) folder contains visual outputs generated by the analysis, including temporal trends, monthly patterns, diurnal profiles, pollutant-weather relationships, weekday–weekend comparisons, correlation analysis, benzene predictions, and Random Forest feature importance.

These outputs are generated from the processed AirQualityUCI data and support the findings presented in the Jupyter notebook, analytical report, and presentation.
