# Source Code

This folder contains the standalone Python script used to reproduce the main analytical outputs of the project.

## `analysis.py`

The script complements the Jupyter notebook by providing a reproducible workflow for:

- Loading and cleaning the raw AirQualityUCI dataset
- Preparing datetime and pollutant variables
- Generating descriptive statistics and temporal aggregations
- Analysing pollutant relationships
- Producing figures and analytical outputs
- Running the predictive modelling workflow

The script uses relative project paths so that it can be run from a cloned copy of this repository.
